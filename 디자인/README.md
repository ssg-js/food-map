# 디자인 파일 관리

- `확정/웹`, `확정/앱`: 승인한 디자인.
- `수정중/웹`, `수정중/앱`: 검토 중인 디자인.
- `보관/초기-v1`: 이전 프로젝트 폴더에서 이관한 초기 디자인과 당시 참고 문서. 현재 구현 지침이 아니다.
- `디자인기준.md`: 디자인 기준과 버전 기록.

모든 디자인은 이 폴더에서 관리한다. 이전작업 폴더는 초기 자료를 보관 영역으로 통합하여 제거했다. v1·v2·v3는 서로 다른 이미지이므로 각 버전을 보존했다.

## 현재 구현과 승인 이력의 관계 · 2026-11-17

확정 시안은 사용자 승인 이력과 시각 토큰을 보존한다. 승인 후 추가된 개인 계정·대표 메뉴·복구·viewport·현재 위치 요구는 `docs/product/personal-service-spec-v1.md` §17과 수정중 05~10 설계에 반영한다. 과거 확정 이미지의 ‘공용/두 그룹/마커 미표시’ 문구를 현재 기능 제약으로 재적용하지 않는다. 수정중 시안의 구현 완료는 사용자 디자인 확정과 구분하며 임의로 확정 폴더로 이동하지 않는다.

배포 전 화면 상태와 사용자 안내 인수 기준은 `수정중/{웹,앱}/09_배포전상태점검/README.md`를 따른다.

신규 공개 이용·데이터 안내 시안은 `수정중/{웹,앱}/10_서비스안내/`에 있다. 운영자/법률 검토 완료 상태와 구분한다.
