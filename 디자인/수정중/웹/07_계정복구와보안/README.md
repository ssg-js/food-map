# 계정 복구와 보안
상태: 구현 기준안. 기존 파랑 #3182f6, 회색 배경/흰 카드, 한 열 폼 재사용.
로그인 하단: 아이디·비밀번호 찾기. 복구 화면: 복구 키(비밀번호처럼 숨김), 아이디 확인 버튼, 새 비밀번호+확인 입력과 재설정 버튼, 로그인으로 돌아가기.
설정 화면: 현재 아이디, 현재 비밀번호로 재인증 → 새 비밀번호/확인 → 변경하고 다시 로그인. 복구 키 발급/재발급은 현재 비밀번호 재인증 후, 기존 키 무효 안내. 키는 발급 응답에서 한 번만 표시하고 보관 확인 후 닫기. 복사 버튼은 사용자의 명시적 조작에서만 실행.
복구 키와 최초 설정 토큰의 용도를 구분한다. 키가 없으면 로그인 후 먼저 발급해야 하며 이메일 찾기 링크는 없다.
오류 role=alert, 성공 role=status, 처리 중 중복 제출 방지. 비밀번호/복구 키는 저장소나 URL에 넣지 않는다.
