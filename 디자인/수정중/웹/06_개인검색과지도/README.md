# 개인 검색과 지도
기존 확정 메인 화면 재사용. 검색폼에 음식 종류·대표 메뉴 보조 입력과 최종 검색어 미리보기 추가. 자동 검색 없이 버튼 제출. 저장 분류는 목적/음식/메뉴 중 최소 하나.
저장 목록 필터 3그룹, 그룹 내부 OR/그룹 간 AND. 카테고리 이름 검색은 저장소 내부 검색만 수행.
현재 페이지 최대 12개 핀을 표시. 카드/핀 선택 양방향 연결, 선택 이름/좌표 표시. 좌표가 없는 결과는 목록 유지, 실패 재조회 제공. 모의 지도는 명시적 배지, 실지도와 구분.

## 기본 진입 위치
진입 즉시 위치 권한 요청, 위치 확인 중에도 기본 지도 표시. 성공 시 현재 위치 중심, 거부·시간 초과 시 기본 지도와 재시도 안내. 사용자 장소 선택은 자동 위치 응답보다 우선한다.
