# 개인 계정 화면 설계
상태: 개발 기준안. Toss 계열 파랑 #3182f6, 밝은 회색 배경, 둥근 흰 카드.
로그인: 아이디, 비밀번호, 로그인 버튼, 일반화된 오류, 처리 중 중복 제출 방지.
최초 설정: 서버에서 발급한 일회용 설정 토큰, 아이디, 비밀번호(12자 이상), 기존 자료 가져오기 선택(기본 해제). 계정 생성 후 로그인.
공개 회원가입 링크 없음. 최초 설정 완료 후 설정 API는 닫힌다.
개인 화면: 우측 계정명과 로그아웃. 관리자 권한 계정만 사용량 이동.
접근성: 명시적 라벨, 자동완성, 오류 role=alert, 키보드 제출.
