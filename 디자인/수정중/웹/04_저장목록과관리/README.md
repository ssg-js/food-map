# 저장 목록·필터·관리 구현 검토안

기존 확정 디자인의 파랑·흰색·회색 토큰, 카드, 선택 칩, 하단 동작을 재사용한다. 사용자 승인 전 확정으로 표시하지 않는다.

- 저장 목록 → 음식 종류·방문 목적 필터 → 선택 장소 지도 → 카테고리 수정/삭제.
- 카테고리 관리 → 이름·분류 수정 → 연결 개수 확인 → 삭제.
- 공용 데이터 수정·삭제는 관리자 권한 확인 후 진행한다.
- 삭제 확인 대화상자와 실패·권한·충돌·정보 없음 상태를 제공한다.

[실제 구현 검증 화면](../../../../docs/screenshots/saved-restaurants-desktop.png)

화면 테스트의 장소/지도는 테스트용 데이터다. 실제 Google 지도 연결은 [별도 캡처](../../../../docs/screenshots/map-real-localhost.png)에서 확인한다. 동일 이미지를 복사하지 않고 검증 파일을 참조한다.
