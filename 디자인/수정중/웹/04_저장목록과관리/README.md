# 저장 목록·필터·관리 구현 검토안

기존 확정 디자인의 파랑·흰색·회색 토큰, 카드, 선택 칩, 하단 동작을 재사용한다. 사용자 승인 전 확정으로 표시하지 않는다.

- 저장 목록 → 음식 종류·방문 목적·대표 메뉴 필터 → 현재 목록 페이지의 장소 지도 → 내 카테고리 수정/저장 해제.
- 카테고리 관리 → 이름·분류 수정 → 연결 개수 확인 → 삭제.
- 내 계정의 맛집·분류만 개인 로그인 세션으로 조회/수정/삭제한다. 공용 데이터용 관리자 접근 키는 사용하지 않는다. 운영자 역할도 타인의 개인 보관함 접근 권한을 의미하지 않는다.
- 삭제 확인 대화상자와 실패·권한·충돌·정보 없음 상태를 제공한다. 카테고리 삭제로 마지막 정상 분류가 없어지면 409와 다른 분류 연결 안내를 보여준다.
- Google 상세 정보 조회에 실패해도 내 분류 수정·저장 해제를 유지한다. 저장 목록은 최대 12개 페이지이며 음식/목적/대표 메뉴 그룹 내부 OR·그룹 간 AND로 결합한다.
