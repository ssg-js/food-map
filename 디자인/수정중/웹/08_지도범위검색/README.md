# 현재 지도 범위 검색
상태: 개발 시안. 기존 파랑 #3182f6·회색 배경·둥근 흰 카드 재사용.
웹: 헤더/계정 행 고정, 남은 viewport 높이에 좌측 패널·우측 지도. 패널 내부만 스크롤. 모바일 웹/앱: 헤더와 지도 고정, 하단 패널만 스크롤, 저장 버튼 별도 고정. 키보드·safe area 고려.
현재 지도 bounds가 준비되면 검색 활성화. 검색 시점의 bounds로만 검색. 이동/확대/축소는 자동 호출하지 않고 마지막 검색 범위와 달라지면 지도 위 ‘현 지도에서 검색’ 버튼 표시. 같은 범위로 돌아오면 숨김. 진행 중 중복 호출 방지.
검색 결과는 좌측 카드와 지도 마커를 같은 placeId로 연결. 카드 hover/focus → 마커 1.2배/위로 강조, 해제 시 복원. 터치 앱은 카드 선택으로 같은 강조. 강조만으로 카메라나 검색 범위가 바뀌지 않는다.
결과 갱신 시 지도를 결과 위치에 맞춰 자동 fit하지 않아 검색한 범위를 유지. 빈 결과·오류·초과 안내 제공, 키 없는 모의 지도는 명확히 표시하고 이동·확대·축소를 직접 조작 가능.
마커/Google 내용은 화면 메모리에만 유지, viewport도 DB에 저장하지 않는다.
