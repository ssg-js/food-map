# 서비스 이용·데이터 안내 · 2026-11-17

상태: 신규 안내 페이지 구현 전 기준안. 사용자 디자인 확정이 아니며 운영자/법률 검토 전 안내 초안이다. 개인용 서비스의 실제 코드 동작을 설명하고, 확정하지 않은 운영자 정보나 보관 기간을 만들어 쓰지 않는다.

## 페이지와 진입

- `/terms`: 공개 서비스 이용 안내. 개인 계정으로 직접 보관하는 서비스, 허용된 음식점 검색/수동 저장/분류 기능, Google 서비스 조건과 관련 링크, 정보 변경·조회 실패/한도 가능성, 공개 회원가입/공유/예약·결제 미제공을 설명한다.
- `/privacy`: 공개 데이터 처리 안내. 계정 식별자·비밀번호 해시·세션·복구 키 해시, Place ID·사용자 분류·연결과 사용량/인증 시도 기록을 설명한다. 비밀번호/복구 키 원문 조회를 제공한다고 쓰지 않는다.
- 로그인 이전에 접근할 수 있어야 한다. 로그인/초기 설정/복구 화면과 개인 서비스 공통 내비게이션에서 링크를 제공한다. 네이티브 앱에는 신뢰한 API 서버의 공개 안내 URL로 이동하는 링크를 제공한다. 로그인 링크와 돌아가기 경로를 유지한다.

## 실제 동작에 맞는 내용

1. 위치 권한을 요청해 지도 중심과 현재 위치 점을 표시한다. 단발 전경 요청이며 백그라운드 추적하지 않는다. 좌표는 화면 메모리에서 사용하고 이 앱의 저장 장소 테이블에 현재 위치를 영구 저장하지 않는다.
2. 실제 Google 검색 시 입력한 검색어와 지도 범위가 서버를 거쳐 Google Places에 전달되고 Google Maps SDK는 지도 표시를 위해 Google에 연결한다. 모의 모드는 외부 실제 검색/지도를 호출하지 않는다.
3. 저장 장소는 Google Place ID와 사용자가 직접 지정한 분류/연결을 보관한다. Google 이름·주소·좌표 등의 표시 정보를 별도 개인 보관 DB의 영구 레코드로 복제하지 않는다. 브라우저 서비스워커도 개인 API/페이지를 영속 캐시하지 않는다.
4. 웹은 HttpOnly 세션 쿠키, 네이티브 앱은 OS 보안 저장소를 사용한다. 비밀번호 변경/재설정은 모든 세션을 폐기한다. 복구 키와 비밀번호를 모두 잃으면 화면의 초기 설정 토큰으로 우회 복구할 수 없다.
5. 사용자는 내 저장·분류를 화면에서 수정/삭제할 수 있다. 계정 자체 삭제와 운영 DB/백업 삭제 절차가 실제 제공되지 않으면 버튼/자동 처리 보장을 만들어 쓰지 않는다.
6. 인프라 제공자, 처리 장소, 운영자 연락처, 계정/인증기록/백업의 구체 보관·파기 기간, 사용자 요청 처리 경로는 운영자가 정해야 한다. 해당 값이 없으면 ‘법적 고지 완료’ 또는 ‘운영 정책 확정’으로 표시하지 않는다.

## 시각·접근성

기존 파랑 #3182f6, 회색 배경, 흰 문서 패널, 본문 16px/행간 1.7, 읽기 폭 약 760px를 사용한다. 웹은 상단 작은 홈/로그인/이용 안내/데이터 안내 내비게이션, 앱 브라우저는 세로 본문과 44px 링크 영역을 제공한다. 긴 문서의 일반 세로 스크롤을 허용한다. 지도 메인 화면의 바깥 스크롤 금지 규칙을 안내 문서에 적용하지 않는다. 제목 계층·보이는 포커스·링크 문구로 목적을 전달한다.

## 수용 기준

- 미인증 상태에서 두 URL이 200이고 실제 내용과 상호 링크를 제공한다. 비밀/실제 사용자 값/키/설정 토큰은 포함하지 않는다.
- Google 약관과 개인정보처리방침의 현재 공식 링크를 제공하고 실제 모드의 Google 데이터 처리 관계를 설명한다. 링크만으로 서비스 운영자의 최종 법적 고지 요구를 충족했다고 단정하지 않는다.
- 운영 미정 항목은 감사 보고서에 배포 전 확인 사항으로 남긴다. 이 시안을 최종 법률 문서로 간주하지 않는다.
- 웹·모바일 폭에서 가로 넘침 없이 키보드로 모든 링크를 이용할 수 있다. 보호 화면·로그아웃·기존 viewport 레이아웃 회귀가 없어야 한다.

공식 근거: [Places API 정책](https://developers.google.com/maps/documentation/places/web-service/policies), 2026-11-17 확인. 공개 이용약관/개인정보처리방침과 Google 조건 연결을 요구하며, 운영자의 법적 적용 판단을 대신하지 않는다.
