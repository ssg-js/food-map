# 배포 전 화면 상태 점검 · 2026-11-17

상태: 기존 페이지의 보완 지시/인수 기준. 새 페이지 제안이나 사용자 디자인 확정이 아니다. 개인용 목표·확정 색상/간격·05~08 컴포넌트를 재사용한다.

## 목적
로그인·저장·지도 등의 성공 화면만으로 배포 가능하다고 오판하지 않도록 실패/권한/복구/좁은 화면 상태를 동일한 기준으로 점검한다. 구현 지시는 `docs/audits/2026-11-17-design-pm-review.md`를 참조한다.

## 기존 화면별 수용 조건

- 로그인/초기 설정: 새 비밀번호 확인을 요구하고 불일치 필드에 오류를 연결한다. 설정 토큰과 복구 키의 용도를 구분한다. 개인 계정이며 공개 가입·공유를 암시하는 문구를 쓰지 않는다.
- 계정 보안/복구: 키 미발급·발급 직후·보관 확인·재발급·잘못된 키·비밀번호 불일치·요청 실패·성공 후 로그인 상태를 구분한다. 비밀 원문은 로그/URL/영속 브라우저 저장에 남기지 않는다. 보관하지 않은 키를 다시 볼 수 있다는 문구를 만들지 않는다.
- 새 장소 검색: 로딩/빈 결과/연결 설정/네트워크/제공자 오류/한도를 구분한다. mock은 실제 장소 조회로 오인하지 않게 표시한다. 키 없는 개발 상태의 기술 설정은 사용자 제품 UI에 무분별하게 늘리지 않는다. 필요한 출처와 제공자 귀속 정보는 결과 가까이에 표시한다.
- 지도: 현재 위치는 별도 파란 점, 결과는 기존 음식점 마커. 위치 거부 시 가짜 현재 위치를 그리지 않는다. 지도 이동만으로 검색하지 않으며 ‘현 지도에서 검색’은 명시적 동작이다.
- 저장/수정: 목적·음식·대표 메뉴 중 하나 이상의 정상 분류를 요구한다. 마지막 정상 분류 삭제/해제, 동시 수정 409, 타 계정/만료 세션을 안내한다. 장소 상세 조회 실패로 분류 수정·삭제가 막히지 않는다.
- 삭제/한도 대화상자: 명확한 제목, 결과/영향 설명, 취소/확인, 중복 제출 방지, 키보드 닫기와 종료 후 합리적 포커스 복귀를 제공한다.
- 관리자: 개인 보관함 권한과 운영자 역할을 구분한다. 모의/실제·내부 예약 수·Google 대조 수·일/월 기준 시간·지도 별도 quota를 혼동하지 않게 표시한다. 내부 잔여 요청을 청구 무료 잔여량으로 표현하지 않는다.
- 연결 끊김: 안내와 재시도 경로를 제공하고 개인 장소·카테고리를 서비스워커의 영속 캐시에 저장하지 않는다. 오프라인 자동 저장 큐는 제공하지 않는다.

## 접근성·반응형 점검

- 키보드 Tab/Enter/Escape 및 보이는 포커스, 입력 라벨/오류 연결, 칩 선택 상태, 상태/오류 안내를 확인한다.
- 핵심 터치 대상은 최소 44px 영역을 확보한다. 지도 위치 표현용 점의 시각 크기와 터치 가능한 음식점/컨트롤의 hit area를 구분한다.
- 좁은 화면/확대 글꼴/키보드/안전 영역에서 검색·확인·취소가 가려지지 않는지 확인한다. 바깥 이중 스크롤과 가로 넘침이 없어야 한다.
- 웹/PWA 브라우저와 Expo 브라우저 렌더러 결과를 iOS/Android 실기기 접근성·권한 검증 완료로 표시하지 않는다.

## 사용자 안내·운영 확인

시안에 그려진 이용약관/개인정보 링크는 정책 원문과 운영자 정보를 대신하지 않는다. 위치 사용, 외부 장소 검색 제공자, 개인 데이터 보관·계정 복구·삭제 절차와 공개 서비스 정책 게시 여부는 실제 운영 방식 및 공식 요구 확인 후 확정한다. 운영자 연락처/도메인을 임의로 만들어 정책 완료로 표시하지 않는다.
