# 맛집지도 디자인 기준 · v1

상태: 메인 화면 검토용 초안. 확정 전이며 다른 페이지 제작은 보류한다.

## 시각 기준
- 토스에서 연상되는 파란색과 명확한 정보 위계를 참고하되 독자적인 화면으로 구성한다.
- 주요 색상 #3182F6, 본문 #191F28, 보조 글자 #6B7684, 배경 #F2F4F6, 표면 #FFFFFF.
- 한국어 산세리프 글꼴, 8px 간격 체계, 카드 모서리 16px, 터치 영역 최소 44px.
- 생성 이미지의 색상과 간격은 근사치이며 구현 시 위 토큰을 적용한다.

## 공통 컴포넌트
- SearchField: 지역·음식·맛집 검색, 입력 지우기, 검색 상태.
- CategoryChip: 전체/한식/일식/카페, 선택 색상과 글자 굵기로 구분.
- RestaurantCard: 사진, 이름, 종류, 별점, 거리, 독립적인 즐겨찾기 버튼.
- MapMarker: 기본/선택 상태. 목록 선택과 지도 선택을 연결한다.
- MapControls: 현재 위치, 이 지역 다시 검색. 웹에서 확대·축소 제공.
- SaveButton: 선택 여부를 아이콘과 접근성 이름으로 전달한다.

## 웹 메인
- 상단 탐색·즐겨찾기 메뉴, 왼쪽 검색·필터·맛집 목록, 오른쪽 지도.
- 목록을 스크롤해도 검색·필터에 접근 가능하게 한다.

## 앱 메인
- 상단 검색·가로 필터, 지도, 높이를 조절하는 하단 목록 시트.
- 하단 탭은 탐색·즐겨찾기·내 정보. 시트와 탭이 겹치지 않도록 안전 영역 확보.
- 시트를 접으면 지도가 넓어지고 펼치면 목록을 탐색한다.

## 검토 후 구현에서 확인할 상태
- 로딩, 결과 없음, 위치 권한 거부, 검색 오류 및 재시도.
- 현재 위치 없이 지역 검색이 가능해야 한다.
- 포커스 표시, 키보드 조작, 텍스트 대비, 화면 읽기 도구 이름을 검증한다.

## 데이터와 범위
- 성수동과 가상의 맛집을 사용하는 시각 시안이다. 지도·거리·별점은 실제 정보가 아니다.
- 생성 이미지로 동작이나 접근성이 검증된 것은 아니다. 실제 지도 API와 데이터 연결은 별도 구현이다.
- 먼저 웹·앱 메인의 색상, 배치, 카드 정보량을 검토한 뒤 공통 컴포넌트를 확정한다.
