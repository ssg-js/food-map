# 메인 화면 v1 검토

- 웹: 목록과 지도가 좌우로 배치되고 첫 맛집 선택이 지도 마커와 연결되어 있다.
- 앱: 검색·필터, 지도, 하단 목록, 탭 순서로 구성되고 하단 목록과 탭이 겹치지 않는다.
- 공통: 파랑 강조색, 둥근 검색창·필터, 사진·별점·거리·저장 버튼이 있는 맛집 카드.
- 현재 결과는 내장 image_gen으로 만든 정적 시안이다. 실행·상호작용 테스트 대상은 아직 없다.
- 생성 이미지의 웹·앱 지도 지형과 일부 마커 모양·식당 표기가 다르다. 검토 후 실제 UI 구현 시 하나의 데이터와 공통 아이콘으로 통일한다.
- 웹 마커의 원화 기호는 가격대 표현이 명확하지 않으므로 구현 시 제거하거나 명시적인 가격 범위로 대체한다.
- 앱 상단은 실제 기기 비율에 맞춰 높이를 조정할 수 있다. 현재 이미지는 구성을 검토하는 시안이다.
- 생성 프롬프트는 각 페이지 폴더의 `생성프롬프트-v1.md`에 보관했다.
- 사용자 확정 전까지 확정 폴더는 비워 둔다. 다른 페이지 제작은 메인 검토 이후에 진행한다.
