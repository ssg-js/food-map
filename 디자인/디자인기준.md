## 화면 범위
- 장소 검색은 입력 중 자동 호출하지 않고 검색 버튼으로 확정한다.
- 검색 후보에는 이름·주소만 표시한다. 선택된 후보에만 카테고리를 연결한다.
- 카테고리는 복수 선택하고 새 이름으로 생성할 수 있다. 검색 필터가 아니다.
- 카테고리 생성 성공 시 선택에 추가한다. 맛집으로 저장 버튼으로 등록한다.
- 현재 지도는 보조 맥락이다. 검색 후보나 등록한 맛집의 마커는 표시하지 않는다.
- 사진·평점·거리·즐겨찾기·프로필·개인 목록·정렬·상세 페이지는 포함하지 않는다.
- 지도 표시 준비 중 안내는 제안된 UX 문구이며 기존 기능 추가를 의미하지 않는다.

## 배치
- 웹: 왼쪽 등록 패널, 오른쪽 기본 지도와 현재 위치 컨트롤.
- 앱: 짧은 지도 영역 아래 등록 시트, 하단 저장 CTA와 안전 영역. v2 작성 후 Expo 앱 코드가 추가되었다. 이 이미지는 네이티브 실행 화면이 아닌 디자인 기준이다.
- 시안은 후보를 선택하고 카테고리를 지정하는 상태를 보여준다. 초기에는 선택 전 등록 영역을 감춘다.

## 재사용할 컴포넌트
- PlaceSearchForm: 라벨·검색 입력·명시적인 검색 버튼.
- PlaceCandidateRow: 이름·주소·선택 체크.
- CategoryPicker: 복수 선택 가능한 체크 칩.
- CategoryCreateForm: 이름 입력·추가 버튼.
- RegistrationAction: 저장 중·완료·오류 피드백.
- MapLocationControl: 현재 위치 이동.

## 시각 토큰
- 주요 색상 #3182F6, 글자 #191F28, 보조 #6B7684, 배경 #F2F4F6, 표면 #FFFFFF.
- 기본 간격 8px, 모서리 16px, 터치 영역 최소 44px.
- 토스의 파랑과 명확한 정보 위계를 참고하며 로고나 고유 화면을 복제하지 않는다.

## 후속 구현 상태
- 검색 로딩·실패·결과 없음, 카테고리 로딩·중복 이름·생성 실패, 저장 중·완료·실패를 다룬다.
- 검색 API 비활성 및 위치 권한 거부 시 기존 오류·기본 위치 동작을 유지한다.
- 새 검색이나 후보 변경 시 기존 선택 초기화는 현재 코드의 동작을 따른다.
- 카테고리는 선택 없이도 현재 코드에서 저장할 수 있으므로 필수 선택으로 바꾸지 않는다.

## 검증 한계
- 내장 image_gen으로 만든 정적 디자인 시안이다. 클릭 동작·접근성·반응형 구현은 검증하지 않았다.
- 장소 이름·주소와 지도는 예시다. 실제 위치를 나타내지 않는다.
- 생성 이미지의 세부 색·간격·문구는 근사치다. 구현 시 이 명세와 실제 API 계약을 따른다.
- 메인 검토 후 다른 페이지에 컴포넌트를 확장하며 사용자 승인 전 확정 폴더로 옮기지 않는다.
