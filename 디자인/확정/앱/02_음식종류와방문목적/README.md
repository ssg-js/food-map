# 음식 종류와 방문 목적 · v3

상태: 검토 중. 기존 확정 v2를 바탕으로 한 추가 기능 시안.

음식 종류와 방문 목적을 각각 복수 선택하고 직접 항목을 추가한다. 그룹·추가 폼·저장 상태는 기능명세서를 기준으로 구현한다. 이미지에 나온 장소와 지도는 가상 예시이며 Google Maps 글자는 공식 출처 에셋의 배치 위치를 나타낸다. 구현 시 공식 브랜드 규칙을 적용한다.

기능명세: `docs/features/place-search-food-purpose-spec.md`

생성 방식: 내장 image_gen. 정적 시안의 핵심 문구·선택 수·그룹 구분을 육안 확인했다. 반응형·접근성·실제 앱 동작은 구현 후 검증한다.
