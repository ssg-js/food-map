# Context
공유 저장소를 개인 서비스로 전환하며 기존 자료를 보존해야 한다.
# Options
직접 비밀번호 구현 대신 Better Auth + Prisma를 선택. OAuth 추가 시 내부 사용자 ID 유지.
# Decision
공개 인증 catch-all과 회원가입 API를 노출하지 않는다. 최초 설정 토큰으로 하나의 계정만 생성하며 사용자명 로그인, 서버 세션 8시간, 웹 HttpOnly 쿠키/앱 Bearer를 사용한다. 기존 자료는 로그인 불가능한 격리 사용자에 보관하고 최초 설정에서 명시적 선택으로 가져온다.
모든 개인 쿼리 ownerId 필터, 연결 테이블 복합 외래키로 계정 간 연결도 DB에서 차단한다. 비밀번호는 인증 라이브러리 해시만 저장. 이메일은 외부 전송 없는 내부 식별자.
# Consequences
실계정 비밀번호를 임의로 만들지 않는다. 소유자가 /setup에서 생성한다. 설정 토큰/인증 비밀은 환경 변수로만 관리한다. 기존 관리자 키로 개인 데이터 접근 불가.
