# 2026-11-12 기능 개발 인수인계

## 완료한 범위

1. 관리자 대시보드: 실제 로그인/로그아웃, 권한 없는 API 차단, 내부 일·월 사용량, 개발 한도 해제 상태 안내, 실제 데이터 차트와 메뉴.
2. 저장한 맛집 목록과 지도: `/saved`, 12개 단위 서버 페이징, Google 표시 정보의 일시 조회, 선택 장소 지도 중심과 핀 갱신.
3. 음식 종류·방문 목적 필터: 그룹 내부 OR, 그룹 간 AND, 초기화와 결과 없음 안내.
4. 맛집 수정·삭제: 기존 연결 불러오기, 관리자 권한 확인, 버전 충돌 409, 삭제 확인, 다른 카테고리/Google 장소 보존.
5. 앱: 저장 목록/관리 화면과 내부 WebView Google 지도 핀, 현재 위치 권한 처리, 외부 지도 대체 동작.
6. 카테고리 관리: 이름과 분류 수정, 미분류 재분류, 연결 개수와 영향 안내, 삭제해도 맛집 보존.

## 확인할 주소

- `http://localhost:3000/map`: 등록과 현재 위치.
- `http://localhost:3000/saved`: 저장 목록·필터·지도·맛집 수정/삭제.
- `http://localhost:3000/categories`: 카테고리 이름·분류 관리.
- `http://localhost:3000/admin/api-usage`: 관리자 사용량.

수정·삭제는 공용 데이터 보호를 위해 관리자 권한이 필요하다. 관리자 화면에 로그인하거나 각 관리 화면의 권한 확인을 사용한다. 접근 키는 로컬 `.env`의 `ADMIN_ACCESS_KEY`이며 커밋하지 않았다. 앱 토큰은 메모리에만 보관한다.

## 실행 명령

Node 24를 사용한다.

```sh
npm run dev
npm run test:product
npm run test:integration
npm run verify:mobile
```

`test:product`는 별도 스키마와 3300번 테스트 서버를 만들고 종료 시 스키마를 정리한다. `test:integration`은 별도 quota_test 스키마를 정리한다. 로컬 DB가 먼저 실행되어 있어야 한다.

## 데이터와 지도 설정

Google 이름·주소·좌표는 DB/영속 캐시에 저장하지 않는다. Restaurant에는 Place ID와 직접 만든 카테고리 관계만 유지한다. 지도 표시 정보는 화면 수명 동안만 보관한다.

현재 키는 Maps Embed를 허용하지 않아 기존 Maps JavaScript provider를 재사용했다. `localhost:3000`은 실제 표시가 확인됐지만 추가 포트의 127.0.0.1 주소는 RefererNotAllowedMapError가 발생했다. 다른 개발 주소/LAN 주소/배포 도메인은 Google 키의 HTTP referrer 허용 목록에 추가해야 한다. 키나 Google Cloud 설정을 자동으로 완화하지 않았다.

사용자 요청으로 개발용 Places 한도 차단은 해제 상태이며 집계는 유지한다. 지도 로드는 Places 카운터와 별도다. 운영 배포 전 개발용 해제 환경변수를 제거한다.

## 검증 한계와 배포 전 남은 범위

- 이 환경에 전체 Xcode/Android SDK가 없어 네이티브 시뮬레이터·실기 실행은 미수행. 앱 UI 브라우저 검증과 양쪽 번들 생성까지 완료했다.
- 실제 휴대폰은 `EXPO_PUBLIC_API_URL`을 컴퓨터 LAN 주소로 설정하고 해당 주소를 지도 키 허용 목록에도 추가해야 한다.
- 개인 계정, 사용자별 비공개 목록, SSO/MFA는 이번 공용 목록 범위에 추가하지 않았다. 현재 관리자 키 인증은 개발/단일 운영자용이다.
- Google Monitoring 연결은 요청대로 미연결 상태다.
- 배포·main 병합은 하지 않았다.
