# Problem
개인용 웹/앱을 클라우드로 옮길 때 평문 외부 API 주소, 익명 지도 프레임, 상태 URL/재로드, 계정 오류와 공개 안내 누락이 있었다.
# Why
로컬에서 정상인 흐름도 배포 도메인·쿠키·기기 저장소·외부 서비스 조건에서는 개인정보 화면과 비용에 영향을 줄 수 있다.
# Decision
새 인프라 대신 기존 인증·메시지 DTO·TanStack Query를 유지하면서 입력 주소, 서버 프레임 경계, 세션/요청 수명과 공개 안내를 보완한다. 실제 배포와 클라우드 값 확정은 따로 검증한다.
# Implementation
앱 HTTPS origin 검증, 보호된 고정 MapFrame과 native Bearer header, 저장 지도 메시지 전환, 계정 ID를 포함한 공통 personalQueryKeys와 owner 범위 갱신, 세션 변경 캐시/토큰 정리와 요청 버전, best-effort 탭 알림, 20초 계정 요청 제한·응답 검증을 적용했다. Google 제3자 귀속과 터치 영역/개인용 copy를 보완했다. 디자인 문서 작성 뒤 공개 이용·데이터 안내와 웹/앱 링크를 만들었다.
# Result
세부 발견·파일·증거·남은 사항은 docs/audits/2026-11-17-frontend-review.md에 기록했다. 자체 웹/앱 린트·타입 검사와 단위 테스트를 통과했다. 제품 UI 결과는 상위 통합 검증 기록을 따른다.
# Retrospective
일반 코드를 정리하는 작업과 운영 정책·실제 도메인/기기 검증은 완료 기준이 다르다. 공개 안내의 운영자/보관 정책을 코드로 임의 확정하지 않는다. 미사용 파일도 런타임·참조 근거 없이 폴더 전체를 삭제하지 않는다.
