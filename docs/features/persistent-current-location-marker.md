# Problem
검색 결과가 생기면 현재 위치 마커가 사라졌다.
# Why
사용자는 음식점과 본인 위치를 함께 비교해야 한다.
# Decision
검색 결과를 현재 위치 표시로 재사용하는 대신, 실제 위치 요청으로 얻은 좌표를 독립된 마커로 관리한다. 별도 API나 지속 위치 추적은 추가하지 않는다.
# Implementation
웹/PWA와 Expo 공통 지도에 userLocation을 전달한다. 현재 위치는 작은 파란 점·흰 테두리·반투명 바깥 원, 음식점은 기존 검색 마커로 표현한다. Google 지도는 위치 점과 장식 원을 별도 ID로 갱신하며 검색 hover 스타일과 클릭 선택 대상에서 제외한다. 모의 지도도 실제 좌표에 독립 표시한다. 선택한 음식점 중심과 실제 사용자 위치는 분리한다. Expo 메시지의 위치 좌표와 중심 이동 버전을 검증한다.
같은 좌표를 다시 받아도 현재 위치 버튼으로 카메라를 복귀시키도록 centerRevision을 전달한다. 위치 권한이 없으면 기본 좌표에 가짜 현재 위치 점을 표시하지 않는다. 지도 밖의 점은 화면에서 보이지 않지만 현재 위치 요청/이동으로 다시 볼 수 있다.
# Result
단위 28건, 웹 제품 40건, Expo 브라우저 UI 6건 통과. 웹/앱 타입·린트와 Next 빌드·Expo QA 번들 생성 성공. 상세 검증 범위는 troubleshooting 문서에 기록했다. GPS 좌표는 메모리에서만 유지하며 DB나 외부 검색 요청에 추가하지 않는다. 마커 두 개만 추가되고 hover·표시 갱신으로 검색 API를 호출하지 않는다.
# Retrospective
단발 위치 요청의 마지막 성공 위치를 표시한다. 실시간 이동 추적은 현재 범위에 포함하지 않는다.
