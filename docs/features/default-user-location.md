# Problem
최초 지도 진입 시 위치 버튼을 누르거나 장소를 선택하기 전까지 지도가 비어 있었다.
# Why
지도 서비스는 사용자의 주변을 기본 화면으로 제공해야 한다.
# Decision
웹/PWA/Expo 지도 진입 시 전경 위치를 1회 자동 요청한다. 지속 추적 대신 12초 제한의 단발 요청을 사용한다. 권한 거부·실패 시 서울시청 중심 기본 지도와 재시도 안내를 표시한다. 기본 좌표를 사용자 위치라고 표시하지 않는다.
# Implementation
위치 요청이 진행 중이어도 기본 지도를 표시한다. 사용자가 선택한 장소를 늦은 자동 위치 응답이 덮지 않도록 요청 버전을 검증한다. 수동 현재 위치 버튼 유지. 위치는 메모리에만 유지한다.
# Result
브라우저 위치 허용·거부·지연 후 장소 선택을 실제 앱 서버에서 검증했다. 기존 제품 흐름을 포함해 20건 통과. 웹/앱 타입·린트와 웹 빌드 및 iOS·Android 번들 생성 확인.
# Retrospective
사용자가 권한을 거부한 경우 권한을 강제할 수 없다. 기본 지도의 서울시청 좌표는 고정 fallback이며 사용자 위치 추정값이 아니다.
