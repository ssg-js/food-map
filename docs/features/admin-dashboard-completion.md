# Problem
관리자 대시보드의 로그인·API·DB 연결과 개발 중 한도 해제 상태의 문구가 검증되지 않았다.

# Why
실제 운영 상태와 다른 비용 보호 안내는 오판을 만든다.

# Decision
기존 디자인 배치와 관리자 인증을 유지하고 내부 집계만 우선 사용한다. 개발 한도 해제와 한도 보호 상태를 구분한다.

# Implementation
관리자 로그인, 권한 없는 API 차단, 일/월 내부 사용량, 실제 데이터 차트, 새로고침과 로그아웃을 지원한다. Google Monitoring은 연결 전까지 미연결로 표시한다.

# Result
린트·타입·빌드 및 로컬 실제 API 검증으로 확인한다.

# Retrospective
개인 계정/SSO와 MFA는 운영 배포 전 별도 인증 단계로 남는다.
