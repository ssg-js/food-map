# 검색 한도와 관리자

서버 DB에서 Google 호출 전에 예약한다. 월 4500회·일100회 상한, 미국 태평양 시간 기준. 실패도 차감하며 DB 오류와 월 설정 누락은 차단한다.

음식 종류·방문 목적 구분과 기존 카테고리 보존을 지원한다. /admin/api-usage에서 관리자 키로 로그인해 내부 사용량을 조회한다. ADMIN_ACCESS_KEY는 32자 이상 서버 환경변수다.

Google Monitoring 연동 코드는 비활성으로 준비되어 있다. 사용자는 내부 카운트만 우선 요청했다.

DB 실행 후 prisma migrate deploy와 search:budget 스크립트로 현재 월을 초기화한다. 기존 사용량 0·다른 곳에서 키 미사용이라는 사용자 확인을 받았다. 다음 월은 자동 개방하지 않는다.

웹 장소 선택 시 Place ID 기반 Google Maps Embed로 위치를 표시한다. Embed는 무료이지만 해당 키의 Maps Embed API 활성화 및 referrer 설정이 필요하다. Google Cloud 설정은 자동 변경하지 않았다. 장소 선택은 추가 Places 요청을 만들지 않으며 좌표는 저장하지 않는다.

검증: 단위16, 웹22, 네이티브UI4 통과(이전 단계). 관리자 추가 후 검증 결과는 작업 완료 시 갱신한다.
