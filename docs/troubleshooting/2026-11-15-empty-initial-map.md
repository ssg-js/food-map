# Problem
live 모드와 키가 설정돼 있어도 처음 진입하면 지도가 비어 있었다.
# Cause
SelectedPlaceMap은 버튼으로 얻은 position 또는 선택 장소 location이 있을 때만 지도 컴포넌트를 렌더링했다. 진입 시 위치 요청이 없었다.
# Solution
웹/PWA/Expo 지도 진입 시 전경 위치 1회 자동 요청. 확인 전에도 서울시청 중심의 기본 지도를 표시하며 실제 사용자 핀과 구분한다. 위치 허용 시 이동, 거부·오류 시 안내와 재시도. 사용자가 선택한 장소를 늦은 자동 응답이 덮지 않도록 요청 버전/선택 식별자를 검증한다. 위치를 DB/브라우저 저장소에 보관하지 않는다.
# Verification
데스크톱·모바일 실제 앱 서버에서 허용 시 지정 좌표 표시, 거부 시 기본 지도·재시도, 늦은 응답 후 장소 선택 유지 검증. 전체 제품 테스트 20건 통과. 웹/앱 린트·타입, Next 프로덕션 빌드, iOS·Android 번들 검증.
# Lessons Learned
위치 권한을 항상 허용한다고 가정하지 않는다. 지도는 위치 확인 상태와 별개로 표시하고, 기본 좌표를 실제 위치로 표현하지 않는다.
